# ♠ Покер для Claude Code

Техасский холдем в боковой панели Claude Code: играйте, пока Claude пишет код.

- 1–6 соперников-ботов
- три уровня: **Новичок** (лузовые «колл-станции», рейзят наугад), **Средний** (играют по силе руки и шансам банка), **Профи** (эквити методом Монте-Карло, ловушки, полублефы, подстраиваются под вашу агрессию)
- сайд-поты, олл-ины, растущие блайнды (каждые 10 раздач)
- партия и статистика сохраняются между сессиями

## Установка

В Claude Code (терминал) введите в промпте:

```
/plugin install poker --marketplace evarabei-steady/claude-poker
```

Ответьте `y` на «Add marketplace?», выберите scope (user — для всех проектов) — и мод сразу активен. Дальше просто `/poker`.

То же самое из шелла:

```
claude plugin marketplace add evarabei-steady/claude-poker
claude plugin install poker@claude-poker
```

Обновление до свежей версии:

```
claude plugin marketplace update claude-poker
claude plugin update poker@claude-poker
```

Требуется Claude Code с поддержкой модов (function hooks).

Для разработки: `claude --plugin-dir ./claude-poker`.

## Игра

```
/poker                  — открыть панель с меню
/poker профи 3          — сразу партия: уровень + число соперников
```

Панель лучше всего смотрится в полноэкранном режиме терминала (≥110 колонок) — она встаёт сбоку от диалога.

| Клавиша | Действие |
|---|---|
| `1` `2` `3` | уровень в меню |
| `1`…`6` | число соперников |
| `f` | фолд |
| `c` | чек / колл |
| `r` | минимальный рейз |
| `h` | рейз ½ банка |
| `p` | рейз на банк |
| `a` | олл-ин |
| `n` | следующая раздача / новая игра |
| `m` | в меню |
| `ctrl+x tab` | перейти в панель из промпта |
| `Esc` | вернуться к промпту |
